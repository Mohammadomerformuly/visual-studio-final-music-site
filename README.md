# Final Music Website

A responsive one-page website created for the Visual Studio final assignment.

## Requirements covered

- Basic HTML webpage
- Embedded YouTube music video
- Custom CSS styling, typography, layout, colours, and responsive design
- JavaScript animation: animated equalizer bars and interactive floating music notes

## Run locally

Open `index.html` in a browser, or serve the folder with any local web server.

## Personalize

The site currently features **Invincible by DEAF KEV**, released by NoCopyrightSounds. To use another favourite song, replace the YouTube embed URL and update the song text in `index.html`.
